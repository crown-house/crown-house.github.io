C Crown Setup Guide

Download, install and start using C Crown in a few minutes.

Download Verify Install Project files Uninstall Troubleshooting

1. Download

Click the button below to download the installer. It is a single file named CCrown_Setup_1.0.0.exe.

Download for Windows

2. Check the file (optional)

To make sure your download is the real one, open Command Prompt in your Downloads folder and run:

certutil -hashfile CCrown_Setup_1.0.0.exe SHA256

The result must match this value:

d6ed79a1d78c9bf5133b3ee6df3bbc45efb0f1a6d5a86e4715b838ee8e5587a7

3. Install

  1. Double-click CCrown_Setup_1.0.0.exe.
  2. If Windows shows a blue “Windows protected your PC” screen, click More info, then Run anyway. See the note below.
  3. Read and accept the license agreement.
  4. Choose the install folder, or keep the default one.
  5. Choose your options: desktop shortcut, opening .cCrown project files with C Crown, opening .c, .cpp and .h files with C Crown, and the folder right-click menu.
  6. Click Install, then Finish to start C Crown.

Why does Windows show a warning?

C Crown is a new program that is not digitally signed yet. Windows warns about every new, unsigned program. If the check in step 2 matches, the file is safe to run. A few antivirus tools may also flag new programs by mistake; if that happens, please contact us.

To install on many computers without any windows, run the installer from Command Prompt:

CCrown_Setup_1.0.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

4. Project files

C Crown saves each project in a file ending with .cCrown. It keeps your project settings in one place.

  • Double-click a .cCrown file to open the project in C Crown.
  • Right-click any folder and choose Open with C Crown to open it in the IDE.
  • Keep the .cCrown file together with your source files when you copy or share a project.

5. Uninstall

Open Settings > Apps, find C Crown and click Uninstall. Your own projects and source files are not deleted.

Troubleshooting

  • The installer does not start: right-click it and choose Run as administrator.
  • The file is blocked or deleted after download: your antivirus may have flagged it by mistake. Check the hash from step 2, then allow the file in your antivirus settings.
  • Double-clicking a .cCrown file does nothing: install again and keep the .cCrown files option selected.
